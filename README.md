# Учебный проект чата

### Навигация:
кастомнвый роутер
Роуты приложения:
* Главная: "/"
* Настройки/профиль: "/settings"
* Страница чата: "/messenger"
* Страница Регистрации: "/sign-up"

### Запуск:
"npm run start" или "npx vite"

### Запуск тестов:
"npm run test"
- тесты используют mocha, chai, sinion
